# Data license

Original derived datasets created by PDHD are intended to be released under **Creative Commons Attribution 4.0 International (CC BY 4.0)** when the project has the legal capacity to license them.

This grant applies only to original PDHD contributions such as project-created identifiers, taxonomic assignments, quality-control fields, provenance records, non-infringing annotations and other original derived metadata.

It does **not** apply automatically to source documents, page images, facsimiles, OCR text, transcriptions or metadata supplied by third parties. Each source is governed by its own rights statement and by `data/catalog/rights_registry.csv`.

Where a row combines original PDHD fields with third-party metadata, reuse must respect both this project license and the terms attached to the underlying source.
